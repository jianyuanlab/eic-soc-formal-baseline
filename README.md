## Overview
This repository establishes the open-access formal baseline specifications, SVA linting rules, and AXI4 formal stub interfaces conforming to the Endogenous Impedance Convergence (EIC v2.0.0) engineering baseline.

## Directory Structure
- docs/: Engineering specifications and SVA verification sign-off guidelines.
- formal/assertions/: Universal SVA formal contract models (EIC-SPEC-01 through 05).
- formal/lint/: Linting constraint rules eliminating simulation race conditions.
- interfaces/: Parameterized AXI4 bridge wrappers and normalized trace schemas.
